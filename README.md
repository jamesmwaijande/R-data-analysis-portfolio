# Statistical Data Analysis & R Markdown Portfolio

This repository contains academic data analysis projects focusing on exploratory data analysis, statistical hypothesis testing, and reproducible reporting built using **R**, **R Markdown**, and the **Tidyverse**.

##  Projects Included

### 1. Higher Education Analytics (`CollegeScores4yr`)
* **Objective:** Analyzed institutional characteristics, costs, admission rates, and geographical distributions across U.S. four-year colleges.
* **Tech Stack:** R, R Markdown, base R graphics.

### 2. College Student Sleep & Behavioral Well-Being (`SleepStudy`)
* **Objective:** Investigated the physiological, behavioral, and academic impacts of sleep habits, chronotypes, and stress among college students.
* **Tech Stack:** R, R Markdown, `tidyverse`, Welch’s two-sample t-tests ($\alpha = 0.05$).
